# Java QCM

Single-page Angular app for Java interview multiple-choice practice. No accounts; progress stays in `localStorage`. FR/EN UI and question banks. Live: https://saidbendrioue.github.io/java-qcm/

## Users

Candidates preparing for Java / Spring / fullstack interviews who want timed mock exams, immediate practice feedback, and spaced review.

## Surfaces

| Route | Mode | Job |
|---|---|---|
| Dashboard | Operate | Accuracy, streak, exam history, export/import |
| Practice | Operate | Filtered one-by-one questions with explanations |
| Exam | Operate | Timed mock (default 80Q / 60min / 85% pass) |
| Review | Operate | Misses, bookmarks, SM-2 due queue |
| Bank / Recent | Operate | Browse and revisit items |

## Constraints

Preserve i18n, dark mode, answer hotkeys, correct/incorrect/flag semantics, and offline local progress.
